# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 0.1.x   | Yes       |

## Reporting a Vulnerability

**Do NOT open a public GitHub issue for security vulnerabilities.**

Use [GitHub Private Vulnerability Reporting](https://github.com/Cipher208/mimocode-ponytail/security).

## Scope

This project is a MiMoCode file hook (~120 lines). Security concerns are limited to:
- Mode file persistence in `~/.config/mimocode/ponytail/`
- Skill file loading from `~/.config/mimocode/ponytail/skills/`
