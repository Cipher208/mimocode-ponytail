# Contributing

1. Fork the repository
2. Create a branch: `git checkout -b feature/my-feature`
3. Make changes to `hooks/ponytail.ts` or `skills/*.md`
4. Test with MiMoCode
5. Commit and push
6. Open a Pull Request

## Testing

```bash
cp hooks/ponytail.ts ~/.config/mimocode/hooks/
cp skills/*.md ~/.config/mimocode/ponytail/skills/
# Restart MiMoCode and test
```
